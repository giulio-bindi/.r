R projects applying quantitative methods — econometrics, network analysis,
statistical modeling — to business and strategy questions. Each project
folder has its own README with method, data sources, and key findings.

## Projects (`/r`)

| Project | What it does |
|---|---|
| [`patent-coinvention-networks`](./r/patent-coinvention-networks) | BSc thesis — bibliometric and co-invention network analysis of global patenting (PATSTAT): concentration, inequality, network structure |
| [`biotech-translation-gap`](./r/biotech-translation-gap) | Panel fixed-effects regression: does the EU convert biotech patents into private R&D as efficiently as the US? |
| [`netflix-tsr-decomposition`](./r/netflix-tsr-decomposition) | McKinsey-style TSR decomposition + panel regression on Netflix and peers — corporate finance/strategy |
| [`patent-landscape-italy`](./r/patent-landscape-italy) | Regional and international patent trend analysis for Italy (OECD data) |
